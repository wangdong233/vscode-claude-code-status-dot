功能点 / Features

1
Tab 五态状态点　每个 CC 会话 tab 的 Claude 图标按状态变色(🟡运行 🟢完成 🔵待输入 🔴中断);收藏会话 tab 标题加 ★ 前缀 + 图标底部金线
2
侧边栏 CC 收藏　Explorer 侧边新增 CC Favorites 视图,把常用文件/会话 pin 在一起;会话图标 open=实心气泡 / closed=轮廓气泡,点击即跳转或恢复
3
底部 4 灯聚合　状态栏左下整体块 🟢done 🟡running 🔵pending 🔴interrupted + 计数,所有会话整体状态一眼看完
4
★ 一键收藏按钮　状态栏 token 旁的 ★/☆ 按钮,一键收藏/取消当前活动 CC 会话
5
右下角 token / $ cost　当前激活会话的 token 用量 + 可选 USD 估算 + 流式速率;点击弹 QuickPick 配置面板
6
完成/中断通知　会话跑完或被限速中断时弹系统通知 + 提示音(前台后台都弹)
