## ✨ Особенности

- 🔧 **Установка в одну строку** — `npx vscode-claude-code-status-dot` само патчит расширение CC, подключает 9 хуков, копирует рантайм-файлы; идемпотентно, можно перезапускать
- 🛡️ **Персистентность — удаление исходников не страшно** — копия рантайма лежит в `~/.claude/cc-status-dot/`, удаление исходников проекта / очистка кеша npx / автообновление CC не затрагивают уже пропатченное расширение
- 🎨 **Полное покрытие четырёх состояний** — полнее, чем родной CC (всего две точки: синяя/оранжевая): idle / running / done / interrupted — всё визуализировано
- 🔔 **Уведомления о завершении/прерывании** — на macOS показывается системное уведомление (выпадает из правого верхнего угла, со звуком `Glass`, без кнопок, исчезает само) **и на переднем, и на фоновом плане**; на Windows/Linux — встроенное сообщение VSCode (правый нижний угол) — можно не смотреть непрерывно
- ⚙️ **Во время workflow держится running** — фоновые subagent/cron в полёте не дают ложного «зелёного», `Stop` — авторитетный арбитр
- 📂 **Синхронизация Open Editors** — в виде «Открытые редакторы» вверху слева вкладка CC тоже несёт статус-точку
- 📊 **4 emoji-шара SBI внизу (v0.1.17: одиночный SBI, компактная конкатенация, зазор 0px, цифры никогда не смещаются)** — левая сторона строки состояния (`StatusBarAlignment.Left` + одиночный SBI с приоритетом `-9996`, у видимого центра) отображает **плотный ряд из 4 emoji-шаров** (v0.1.17 объединяет ряд 4-SBI из v0.1.16 обратно в один SBI, чей текст — конкатенация 4 сегментов `🟢3🟡1⚪0⚪0` — первопричина: `statusbarpart.css` VSCode жёстко задаёт `margin:0 3px;padding:0 5px` на каждый SBI (~6-16px зазор между соседними SBI, не управляется через публичный API; «рыхлый зазор», который вы видели в v0.1.16 — это хард-лимит фреймворка, только одиночный SBI даёт настоящую компактность): 🟢готово / 🟡выполняется / 🔵ожидание / 🔴прервано. Токен каждого света — `<шар><цифра>` (шар несёт свой собственный цвет); 4 токена конкатенируются **без разделителя** (**зазор 0px между светами** — ширина строки сжимается с ~120px до ~70px); количества ограничены 0/1/2/3/N (>=4 показывает N); количество>0 → шар горит (🟢/🟡/🔵/🔴 предокрашенные + цифра прямо рядом), количество=0 → серый шар ⚪ + «0». 🔵 = ожидание ввода пользователя (permission/question/elicit, питается от случая Notification hook). Готово старше >5 мин считается idle (не зелёное). **«Цифры никогда не смещаются» гарантируется правилом CSS `font-variant-numeric:tabular-nums` самого VSCode** (statusbarpart.css применяет tabular-nums к каждому элементу строки состояния — ASCII-цифры 0-9 одинаковой ширины в любом шрифте), независимо от рендеринга emoji-шрифта. v0.1.17 использует **1 runtime StatusBarItem + конкатенированный текст** (без патча package.json CC, без блока ThemeColor, IIFE мутирует text напрямую каждые 500мс).
- ↩️ **Откат в один клик без побочных эффектов** — `--revert` полностью восстанавливает `extension.js` из `.bak`, хирургически убирает хуки, сохраняет ваши пользовательские данные

> ⚠️ **Честное заявление**: этот проект — **патч, а не самостоятельное расширение** — VSCode не позволяет сторонним расширениям менять иконку webview-вкладки другого расширения, единственный рабочий путь — пропатчить `extension.js` самого CC. Расплата: автообновление CC перезапишет патч, нужно перезапустить команду.

## 💬 Что вы получите?

После установки, пока Claude Code выполняет задачу, **с одного взгляда видно, чем занята каждая сессия**:

| Сценарий | Вы видите / получаете |
|---|---|
| CC работает (вы отправили prompt) | 🟡 иконка вкладки — **статическая жёлтая точка** `#CCA700` (без анимации) |
| CC штатно завершил раунд | 🟢 вкладка зеленеет + приходит системное уведомление macOS (правый верхний угол + звук `Glass`, без кнопок) — и на переднем, и на фоновом плане |
| CC упёрся в rate limit / перегруз и прервался | 🔴 вкладка красно мигает + уведомление (в тексте причина — `rate limit reached` и т. п.) |
| workflow / фоновый subagent ещё работает | вкладка главной сессии **остаётся жёлтой** (без ложного «зелёного»), авторитетный арбитр `Stop` не даёт ложного завершения |
| Смотреть вид «Открытые редакторы» вверху слева | вкладка CC **тоже несёт статус-точку**, полностью синхронно с верхней панелью вкладок |
| CC запрашивает разрешение | 🔵 синяя точка (**родное поведение CC, проект её не переопределяет**) |

> **Всё работает сразу после установки, никакой настройки не требуется.** Конфиг нужен только чтобы выключить уведомления / поменять звук.

## 🚀 Быстрый старт

### ① Проверьте предварительные требования

- **Node.js 18+**
- **Установлено VSCode-расширение Claude Code** (т. е. в VSCode можно открыть панель чата CC)

### ② Установка в одну строку

```bash
npx vscode-claude-code-status-dot
```

Эта команда сама:
1. Найдёт в `~/.vscode/extensions` (а также insiders / cursor / vscodium и т. д.) `anthropic.claude-code-*` и выберет старшую версию;
2. Автоматически вычистит остатки старой версии (если есть);
3. **Зарезервирует** `extension.js` → `extension.js.bak` (только при первом запуске);
4. Внедрит таймер (установка иконки вкладки + уведомления done/interrupted);
5. Запишет **9 событий хуков** в `~/.claude/settings.json` (с пометкой `# cc-status-dot-managed`, идемпотентно);
6. Скопирует рантайм-копию (4 SVG = idle + running + done + error, плюс скрипты хуков) в `~/.claude/cc-status-dot/` (`INSTALL_DIR`).

> **Или из исходников (режим разработки)**:
> ```bash
> git clone https://github.com/wangdong233/vscode-claude-code-status-dot.git
> cd vscode-claude-code-status-dot
> npx tsx patch.ts
> ```
> Оба способа эквивалентны и идемпотентны. IIFE и хуки ссылаются на абсолютный путь `INSTALL_DIR` — **удаление исходников проекта / очистка кеша npx не влияют на уже пропатченное расширение**.

### ③ Перезагрузите окно

`Cmd+Shift+P` (Mac) / `Ctrl+Shift+P` (Win/Linux) → введите `Developer: Reload Window`.

### ④ Отправьте prompt и наблюдайте

В CC отправьте prompt:
- иконка вкладки становится 🟡 **статической жёлтой точкой** → CC завершает → становится 🟢 зелёной
- дождитесь завершения CC → придёт системное уведомление macOS (правый верхний угол + звук `Glass`, без кнопок, исчезает само) — **и на переднем, и на фоновом плане**

## 🎨 Цвета состояний

| Цвет | Значение | Триггер |
|---|---|---|
| 🟡 Жёлтый `#CCA700` (**статичный**, без анимации) | Выполняется | Отправка prompt, до/после вызова инструмента (heartbeat), spawn subagent |
| 🟢 Зелёный `#3FB950` (статичный) | Раунд завершён | CC вызывает `Stop` (**через 5 минут автоматически сереет**) |
| 🔴 Красный `#F85149` (быстрое мигание) | Прервано / ошибка | CC вызывает `StopFailure` (rate limit, перегруз и т. п.) |
| ⚪ Серый `#808080` (статичный) | Простой | Начальное состояние / завершено более 5 минут назад / нет файла состояния |
| 🔵 Синий (родной CC) | Ждёт авторизации | Родная синяя точка CC, **проект её не переопределяет** |

> running — статическая жёлтая точка (без анимации); interrupted — быстрое мигание как аварийный сигнал. Полный контракт состояний (события / SVG / IPC / уведомления) — в [`docs/STATES.md`](docs/STATES.md).

## 🛠️ Подробно о возможностях

### 🟡 Четырёхсостояная точка иконки вкладки

Иконка вкладки каждой сессии CC меняет цвет по состоянию, **отображается и в верхней панели вкладок, и в виде «Открытые редакторы» вверху слева**. running/idle/done — статические точки, interrupted — быстрое мигание.

### 🔔 Уведомления о завершении / прерывании

При переходе сессии в `done` или `interrupted` (только в момент самого перехода, без повторов):

- **macOS**: показывается системное уведомление (выпадает из правого верхнего угла, со звуком `Glass` по умолчанию, без кнопок, через несколько секунд исчезает само) — **и на переднем, и на фоновом плане** (`ccStatusDot.notifyWhenFocused` по умолчанию `true`);
- **Windows / Linux**: без `osascript` откатывается до встроенного сообщения VSCode (правый нижний угол, тоже без кнопок, исчезает само).

На done и прерывание играется `ccStatusDot.notifySound` (по умолчанию `Glass`). При первом системном уведомлении macOS один раз спросит разрешение «Script Editor хочет отправлять уведомления» — разрешите.

### ⚙️ Во время workflow держится running

Во время выполнения workflow / subagent в фоне главная сессия остаётся жёлтой (без ложного «зелёного»), не сообщает о завершении ошибочно.

### 📂 Синхронизация Open Editors

В виде «Открытые редакторы» вверху слева вкладка CC **тоже несёт статус-точку**, полностью синхронно с верхней панелью вкладок.

<details>
<summary>📖 Механизм персистентности (почему удаление исходников не страшно)</summary>

Пути SVG, на которые ссылается reader (внедрённый IIFE), и команды хуков, подключённые в settings.json, указывают на **абсолютный путь** `INSTALL_DIR` (`~/.claude/cc-status-dot/`), а не на каталог исходников проекта. При установке patcher идемпотентно копирует туда материалы из исходников (`resources/` + `hooks/`). Поэтому даже если:
- удалить каталог исходников проекта
- очистится кеш npx
- CC автообновится (перезапишет только каталог расширения, не трогая `~/.claude/`)

пропатченное расширение продолжит рендерить как обычно. После обновления CC нужно лишь **один раз перезапустить** `npx vscode-claude-code-status-dot`, чтобы восстановить патч.

</details>

<details>
<summary>📖 Путь обновления (как апгрейдиться со старой установки через git clone)</summary>

Пользователям старых версий достаточно перезапустить `npx vscode-claude-code-status-dot` — patcher обнаружит старую логику внедрения → автоматически восстановит оригинал → заново внедрит новую версию, **`--revert` перед переустановкой не нужен**.

</details>

<details>
<summary>📖 Почему патч (а не самостоятельное расширение)</summary>

Иконка вкладки `WebviewPanel` VSCode (`iconPath`) **монопольно задаётся расширением, создавшим эту панель** — публичного API, позволяющего стороннему расширению менять её, нет. Session-вкладка CC — это как раз WebviewPanel, созданный самим расширением CC, и её иконку можно установить только внутри `extension.js` CC. Все альтернативы (самостоятельное расширение, proposed API, перехват webview и т. п.) оказались недоступны — единственный рабочий путь это патч. Расплата: автообновление CC перезапишет патч, нужно перезапустить команду.

</details>

<details>
<summary>📖 Сводка команд</summary>

| Команда | Назначение |
|---|---|
| `npx vscode-claude-code-status-dot` | Установка (патчит extension.js + подключает хуки, идемпотентно; автоматически вычищает остатки старой версии) |
| `npx vscode-claude-code-status-dot --revert` | Откат (восстановление из `.bak` + удаление хуков + удаление INSTALL_DIR, пользовательские данные сохраняются) |
| `npx vscode-claude-code-status-dot --status` | dry-run-отчёт, ничего не меняет |

В режиме разработки замените команду на `npx tsx patch.ts` (с теми же аргументами).

</details>

## ⚙️ Конфигурация (опционально)

Добавьте в `settings.json` VSCode (если не настраивать — используются значения по умолчанию):

```json
{
  "ccStatusDot.notify": true,
  "ccStatusDot.notifyWhenFocused": true,
  "ccStatusDot.notifySound": "Glass"
}
```

| Параметр | По умолч. | Описание |
|---|---|---|
| `ccStatusDot.notify` | `true` | Общий переключатель уведомлений |
| `ccStatusDot.notifyWhenFocused` | `true` | Показывать уведомления и когда VSCode на переднем плане (если иконки достаточно — держите false) |
| `ccStatusDot.notifySound` | `"Glass"` | Звук системного уведомления macOS (общий для done и прерывания; `""` — без звука; возможны Basso/Ping/Hero и т. п.) |

## ❓ FAQ

**После обновления CC статус-точка не загорается?**
Автообновление CC полностью заменяет каталог расширения, пропатченный файл перезаписывается оригиналом. Перезапустите `npx vscode-claude-code-status-dot` (копия рантайма SVG/хуков лежит в `~/.claude/cc-status-dot/`, обновление CC её не трогает; удаление исходников проекта тоже не влияет).

**Сразу после установки иконка не изменилась?**
Сначала `Developer: Reload Window`. Если не помогло, запустите `npx vscode-claude-code-status-dot --status`: `patched: no` — перезапустите; `baked RES ... (STALE)` — перезапустите для переписывания на месте; `hooks wired: no` — перезапустите; `missing SVGs` — перезапустите для дозаполнения.

**Апгрейд со старой версии (через git clone)?**
Просто перезапустите `npx vscode-claude-code-status-dot` — апгрейд старой версии обрабатывается автоматически, `--revert` перед переустановкой не нужен.

**Состояние застряло в running?**
Скорее всего вы прервали CC через Esc (CC не вызывает Stop/StopFailure, хука нет). Следующий prompt или штатное завершение поправят состояние сами.

**`npx` не подключается?**
Запасной вариант — глобальная установка:
```bash
npm i -g vscode-claude-code-status-dot
vscode-claude-code-status-dot        # после установки запустите команду напрямую
```

## ⚠️ Известные ограничения

- **Ручное прерывание через Esc не даёт хука**: CC не вызывает Stop/StopFailure ([#45289](https://github.com/anthropics/claude-code/issues/45289)/[#9516](https://github.com/anthropics/claude-code/issues/9516)), состояние зависнет в running до следующего prompt/Stop.
- **Автообновление CC перезаписывает патч**: пропатченный `extension.js` заменяется оригиналом → тихо падает, перезапустите команду для восстановления.
- **Хрупкость minified-anchor**: патч опирается на две точные строки в коде CC, при дрейфе версий patcher сообщит "Anchor mismatch" и откажется писать (расширение не сломается).
- **При полном закрытии VSCode уведомлений нет**: IIFE живёт в процессе extension host, при закрытии VSCode он не работает → без уведомлений.
- **Клик по системному уведомлению не переключает на вкладку**: у osascript нет click-callback, уведомление только напоминает, возврат в VSCode — по зелёной/красной точке вкладки.

## 🏗️ Архитектура + документация

**Патчит `extension.js` CC (внедряет таймер, устанавливающий иконку вкладки) + хуки CC пишут состояние + уведомления о завершении/прерывании.** Полная документация:

- [`docs/STATES.md`](docs/STATES.md) — **контракт состояний (единственный источник истины)**: четыре состояния / отображение событий / IPC / уведомления
- [`docs/DESIGN-injection.md`](docs/DESIGN-injection.md) — принцип внедрения иконки (anchor / IIFE / привязка SVG)
- [`docs/USAGE.md`](docs/USAGE.md) — руководство по использованию (установка / диагностика / откат)

> Этот проект модифицирует `extension.js` расширения CC (с резервной копией, `--revert` полностью восстанавливает), а также пишет в `~/.claude/settings.json` (при первом запуске делает резервную копию). Скрипты хуков спроектированы так, чтобы **никогда не блокировать и не прерывать CC** — любая ошибка тихо делает `exit(0)`.
