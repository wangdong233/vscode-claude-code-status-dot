> Когда параллельно открыто несколько сессий Claude Code, постоянно перещёлкивать вкладки — кто закончил, кто ждёт авторизации, кого прибил rate limit — утомляет. Поставьте это, и **каждая вкладка сама скажет, чем занята**, а внизу окна одной строкой видна сводка по всем сессиям; когда работа завершена или прервана — мелькнёт системное уведомление. Можно смело переключаться на другое дело.

</div>

**① Пятисостояная точка на вкладке**　Иконка Claude на вкладке каждой CC-сессии меняет цвет по состоянию — 🟡 выполняется / 🟢 завершено / 🔴 прерывание (быстрое мигание) / ⚪ простой / 🔵 ждёт ввода. У 🔵 (ждёт ввода) два триггера: (a) когда CC показывает диалог авторизации — reader уступает место родной синей точке CC (**не переопределяет** её); (b) когда ответ Claude содержит семантику «ждёт вашего решения» (`等你`/`你决定`/`请确认`/`let me know`/`your call` и т. п.) — вкладка автоматически синеет (поверх running-жёлтого / done-зелёного), чтобы одним взглядом отличить «реально закончил» от «ждёт, пока я что-то скажу» — не нужно гадать, глядя на вкладку. У избранных сессий к заголовку вкладки добавляется префикс **★** + золотая линия под иконкой; у архивированных — префикс **●** + серая линия под иконкой (избранное и архив взаимно исключают друг друга, одна сессия — только одно из двух). Отображается и в верхней панели вкладок, и в боковой панели «Открытые редакторы» — обе синхронны.

**② Боковая панель CC Избранное / CC Архив**　В боковой панели Explorer добавлено два представления — CC Favorites + CC Archive (взаимно исключают друг друга: сессия может находиться только в одном из них); в «Избранном» часто используемые сессии/файлы закреплены вместе, в «Архив» убраны пока не нужные сессии. Иконки сессий: open=сплошной пузырь / closed=пузырь одним контуром, клик переключает на сессию или выполняет resume в новую panel; внутристрочные кнопки переключают между видами — в избранном [Архивировать][Открыть][Убрать], в архиве [В избранное][Открыть][Убрать], клик по «Архивировать»/«В избранное» автоматически убирает сессию из другого представления. Правый клик по закрытой сессии копирует команду `claude -r <sid>`. Строки в обоих представлениях можно **перетаскивать для сортировки** — сброс на строку вставляет перед ней, сброс за последнюю строку перемещает в конец. После первого перетаскивания список переходит в ручной порядок (новые записи по-прежнему появляются сверху); сбросы без изменений ничего не пишут на диск.

**③ Агрегат из 4 огней внизу**　Один общий блок в строке состояния: 🟢 done · 🟡 running · 🔵 pending · 🔴 interrupted + счётчики — общее состояние всех сессий видно одним взглядом, без переключения вкладок; позиции 4 огней зафиксированы, изменение чисел не сдвигает ряд.

**④ ★ «В избранное» / ○ «В архив»**　Рядом со счётчиком токенов в строке состояния — две кнопки: ★/☆ одним кликом добавляет текущую активную CC-сессию в избранное или убирает (в избранном — сплошная золотая ★, не в избранном — пустая ☆); ○/● одним кликом архивирует или убирает из архива (в архиве — сплошной серый круг ●, не в архиве — пустое серое кольцо ○). Избранное и архив взаимно исключают друг друга — клик по одной кнопке автоматически снимает другую; при отсутствии активной CC-сессии обе кнопки автоматически скрываются.

**⑤ token / $ cost в правом нижнем углу**　Расход токенов текущей активной сессии + опциональная оценка в USD + скорость стриминга (tok/s); клик открывает панель настройки QuickPick (окно статистики / режим отображения / уведомления / звук / копировать / сбросить), панель следует языку интерфейса VSCode (zh/en/ja/de/es/fr/pt/ru).

**⑥ Уведомления о завершении / прерывании**　Когда сессия завершается или прерывается rate limit'ом — всплывает системное уведомление + звук (macOS: выпадает из правого верхнего угла / Windows·Linux: toast в правом нижнем углу), и на переднем, и на фоновом плане — можно переключиться на другое дело и всё равно быть в курсе.

> **Гарантии надёжности**: когда автообновление CC перезаписывает патч, companion-расширение автоматически переприменяет его + предлагает reload (незаметное восстановление); перед патчем полный `extension.js` (2.6 МБ) проверяется через `node --check` + атомарная запись (**CC никогда не сломается**); `--revert` — откат в один клик без побочных эффектов; рабочая копия лежит в `~/.claude/cc-status-dot/` (удаление исходников / очистка кеша / обновление CC не влияют на установленное). Во время выполнения workflow-субагентов главная сессия остаётся 🟡 без ложного «зелёного».

## 🚀 Три шага до результата

**Предварительные требования**: Node.js 18+ и установленное расширение Claude Code в VSCode.

```bash
npx vscode-claude-code-status-dot
```

`Cmd+Shift+P` (Mac) / `Ctrl+Shift+P` (Win/Linux) → введите `Developer: Reload Window` → отправьте промпт в CC.

Иконка вкладки тут же станет 🟡 жёлтой, а когда CC закончит — позеленеет 🟢 и прилетит уведомление. **Когда CC запросит разрешение — вкладка уступит место родной 🔵 синей точке CC (permission yield), а внизу 🔵 лампа pending увеличится на 1.** Ставится один раз, работает сразу, никакой настройки не требуется.

> Конфиг понадобится только если захотите выключить уведомления или поменять звук — см. раздел [Конфигурация](#-конфигурация-опционально).

## ⚙️ Конфигурация (опционально)

**Два способа изменить конфигурацию**: ① клик по токеновому SBI в правом нижнем углу → всплывает панель QuickPick (графическая, следует языку интерфейса VSCode zh/en/ja/de/es/fr/pt/ru); ② прямое редактирование `settings.json` (таблицы по функциональным блокам ниже). Без настройки используются значения по умолчанию.

### 1. Уведомления (соответствует функции ⑥)

Системные уведомления + звук при завершении / прерывании (macOS: правый верхний угол / Win·Linux: toast в правом нижнем углу, и на переднем, и на фоновом плане).

| Параметр                        | По умолч. | Описание                                                                                                 |
| ------------------------------- | --------- | -------------------------------------------------------------------------------------------------------- |
| `ccStatusDot.notify`            | `true`    | Общий переключатель уведомлений                                                                          |
| `ccStatusDot.notifyWhenFocused` | `true`    | Показывать и на переднем плане; `false` — уведомления только в фоне                                      |
| `ccStatusDot.notifySound`       | `"Glass"` | Звук уведомления macOS (общий для done и прерывания; `""` — без звука; возможны Basso/Ping/Hero и т. п.) |

### 2. Статистика токенов и стоимость (соответствует функции ⑤)

Токеновый SBI в правом нижнем углу показывает расход токенов текущей активной сессии + опциональную оценку в $ + скорость стриминга; токены workflow-субагентов тоже учитываются (не останутся «невидимыми»).

| Параметр                            | По умолч.   | Описание                                                                                                                                                                  |
| ----------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ccStatusDot.tokenStatsWindow`      | `"all"`     | Временное окно: `all` = накопительный итог (вся сессия, без сброса); `5min/10min/1h/24h/3d/7d/30d` = скользящие окна (старые turn'ы уходят из окна, выглядит как «сброс») |
| `ccStatusDot.tokenDisplayMode`      | `"both"`    | Режим отображения: `token` только токены / `cost` только $ / `both` оба                                                                                                   |
| `ccStatusDot.rateDisplayMode`       | `"numeric"` | Отрисовка скорости стриминга: `off` / `numeric` (напр. `1.2k/s`) / `sparkline` (`▁▂▃▄▅▆▇█` мини-график) / `both`; при перегруженной строке состояния переключите на `off` |
| `ccStatusDot.tokenSbiVisible`       | `true`      | Показать / скрыть токеновый SBI                                                                                                                                           |
| `ccStatusDot.tokenLiveDeltaEnabled` | `true`      | Во время стриминга обновлять токены в реальном времени; на чувствительных к производительности машинах поставьте `false`                                                  |
| `ccStatusDot.showCost`              | `true`      | Показывать `$` (неизвестные модели скрываются автоматически; требуется запись в `token-rates.json`)                                                                       |
| `ccStatusDot.warnThresholdUsd`      | `0`         | Уведомление при превышении порога стоимости (`0` = выключено; положительное число = USD-порог, срабатывает один раз за превышение)                                        |

> **Собственные цены моделей**: `~/.claude/cc-status-dot/token-rates.json` — горячо-перезагружаемая таблица цен (по умолчанию покрывает официальные цены Anthropic; модели без совпадения типа GLM автоматически прячут `$`). Добавьте glob, чтобы показать `$`:
>
> ```jsonc
> {
>   "_default": null,
>   "claude-sonnet-*": { "in": 3, "out": 15, "cacheRead": 0.3, "cacheCreate5m": 3.75, "cacheCreate1h": 6 },
>   "glm-*": { "in": 0.5, "out": 1.5 },
> }
> ```

### 3. Избранное / Архив (соответствует функциям ②④)

Представления CC Favorites + CC Archive в боковой панели (взаимно исключают друг друга) + отметки ★/● на вкладке + кнопки ★/○ в строке состояния. Архив полностью зеркалит избранное — дополнительной настройки не требуется.

| Параметр                                       | По умолч. | Описание                                                                                                                  |
| ---------------------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------- |
| `ccStatusDot.fav.includeInExplorerContextMenu` | `true`    | Показывать в контекстном меню Explorer «Добавить/убрать из избранного CC»; при перегруженном меню можно поставить `false` |

## ❓ FAQ

**После обновления CC статус-точка не загорается?**
Автообновление CC полностью заменяет каталог расширения, пропатченный файл перезаписывается оригиналом. **Начиная с v0.2.0**: companion-расширение при старте VSCode проверяет маркер `cc-status-dot-injected` и, если CC снёс патч, автоматически перезапускает `node ~/.claude/cc-status-dot/patch.js` и предлагает `Reload Window` в один клик — в большинстве случаев вам ничего делать не нужно. Если companion не установлен или хотите починить вручную: перезапустите `npx vscode-claude-code-status-dot` (копия рантайма SVG/хуков лежит в `~/.claude/cc-status-dot/`, обновление CC её не трогает; удаление исходников тоже не влияет).

**Сразу после установки иконка не изменилась?**
Сначала `Developer: Reload Window`. Если не помогло, запустите `npx vscode-claude-code-status-dot --status`: `patched: no` — перезапустите; `baked RES ... (STALE)` — перезапустите для переписывания на месте; `hooks wired: no` — перезапустите; `missing SVGs` — перезапустите для дозаполнения.

**Апгрейд со старой версии (через git clone)?**
Просто перезапустите `npx vscode-claude-code-status-dot` — апгрейд старой версии обрабатывается автоматически, `--revert` перед переустановкой не нужен.

**Состояние застряло в running?**
Скорее всего вы прервали CC через Esc (CC не вызывает Stop/StopFailure, хука нет). Следующий промпт или штатное завершение поправят состояние сами.

**`npx` не подключается?**
Запасной вариант — глобальная установка:

```bash
npm i -g vscode-claude-code-status-dot
vscode-claude-code-status-dot        # после установки запустите команду напрямую
```

## ⚠️ Известные ограничения

- **Ручное прерывание через Esc не даёт хука**: CC не вызывает Stop/StopFailure ([#45289](https://github.com/anthropics/claude-code/issues/45289)/[#9516](https://github.com/anthropics/claude-code/issues/9516)), состояние зависнет в running до следующего промпта/Stop.
- **Автообновление CC перезаписывает патч**: пропатченный `extension.js` заменяется оригиналом → **начиная с v0.2.0 companion-расширение автоматически перезапускает patcher + предлагает reload** (см. FAQ); без companion — перезапустите команду вручную.
- **Хрупкость minified-anchor + безопасность**: патч опирается на две точные строки в коде CC, при дрейфе версий patcher сообщит "Anchor mismatch" и откажется писать. Дополнительно перед записью `extension.js` патчер прогоняет `node --check` по полному 2.6 МБ файлу (assertCompiles-страж: кривой IIFE не записывается), пишет через атомарный `.tmp` + rename, автоматически перепроставляет `INJECT_VERSION` — **CC никогда не будет испорчен**.
- **При полном закрытии VSCode уведомлений нет**: IIFE живёт в процессе extension host, при закрытии VSCode он не работает → без уведомлений.
- **Клик по системному уведомлению не переключает на вкладку**: у osascript нет click-callback, уведомление только напоминает, возврат в VSCode — по зелёной/красной точке вкладки.
- **SBI priority без права собственности**: блок в нижней строке состояния занимает `StatusBarAlignment.Left` с priority `-9996` (одна точка); у VSCode StatusBarItem API нет расширительного namespace/владения — другое расширение с тем же priority может отодвинуть наш блок в угол. **Архитектура с единым блоком из одного StatusBarItem устраняет класс отказов «строка разрезана внешним SBI»** (4 отдельных SBI могли бы быть разделены вставкой чужого элемента между лампами; единый блок гарантирует, что внешняя вставка может лечь только по бокам). В типичных сценариях не срабатывает; см. STATES.md §7.5.
- **Зависимость от emoji-стека шрифтов**: кружки в нижней строке — это emoji-глифы (🟢🟡🔵🔴⚪), полагающиеся на системный emoji-шрифт. На macOS (Apple Color Emoji), Windows 10+ (Segoe UI Emoji) и большинстве дистрибутивов Linux (Noto Color Emoji) отображаются цветными; на Win7 / в headless-Linux / на удалённых SSH без emoji-шрифтов могут стать чёрно-белыми или «тофу». Это осознанный компромисс (emoji-кружки визуально приятнее кросс-платформенных цветных квадратов).

> Этот проект модифицирует `extension.js` расширения CC (с резервной копией, `--revert` полностью восстанавливает), а также пишет в `~/.claude/settings.json` (при первом запуске делает резервную копию). Скрипты хуков спроектированы так, чтобы **никогда не блокировать и не прерывать CC** — любая ошибка тихо делает `exit(0)`. Подключено **9 хуков** (включая `Notification`, пишущий pending).
